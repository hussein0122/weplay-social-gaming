# WePlay Social Gaming

منصة ألعاب اجتماعية متعددة اللاعبين، عربية أولًا مع دعم الإنجليزية، مستوحاة من فئة تطبيقات الألعاب الاجتماعية مع هوية وتصميم أصليين.

## التقنية المستهدفة
- Next.js App Router + React + TypeScript
- Tailwind CSS
- Supabase Auth, PostgreSQL, Realtime, Storage
- WebRTC/LiveKit للصوت عند إعداد مزود الاتصال
- PWA وتجربة Mobile-first

## مراحل التنفيذ
1. تأسيس واجهة التطبيق ونظام التصميم والتنقل RTL/LTR.
2. تسجيل الدخول والملفات الشخصية والأصدقاء.
3. غرف الألعاب واللعب الجماعي مع حالة موثوقة على الخادم.
4. الرسائل والغرف الصوتية والإشعارات.
5. التقدم والمكافآت ولوحة الإدارة، ثم الاختبارات والنشر.
